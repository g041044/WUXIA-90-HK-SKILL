## 使用目标与边界

把参考视频拆成可复用的视觉语法，用于扩展色彩、灯位、布景、人物造型、脸部差异和表演动作。只提炼关系，不复刻具体演员、角色、服装、场景、字幕、特效造型或完整镜头顺序。

参考视频只回答以下问题：

- 什么区域最亮，亮度怎样引导视线？
- 哪些颜色属于环境，哪些颜色属于人物或剧情转折？
- 光源如何进入布景并随火焰、水面、遮挡和人物移动变化？
- 布景靠什么建立前中后景与可行动空间？
- 人物靠什么轮廓、材质、发型和面部特征被识别？
- 眼睛先看哪里，头部何时跟随，身体怎样泄露真实态度？
- 动作如何预备、触发、传力、结束并留下余势？
- 双人和多人关系如何通过距离、高度、遮挡、接触与运动方向表达？

不要把某条参考中的蓝色、柔光、白衣或烛阵当成默认答案。先提炼功能，再为当前剧情寻找新的物理载体。

## 八轴提炼法

分析参考视频或设计原创场景时，依次选择以下八轴。每轴只确定一个主方案，必要时增加一个对置方案：

1. **曝光轴**：高调乳白、中间调暖润、低调彩色夜景、火光深黑或尘日逆光。
2. **颜色轴**：一个环境主色、一个人物对置色、一个小面积点睛色和一个受保护肤色。
3. **亮源轴**：火焰、灯阵、窗格、天井、月洞、水面、纱幕、雪地、沙地或特效能量。
4. **空间轴**：纵深通道、中心仪式、环形包围、高低权力台阶、可穿越帘幕或开阔战场。
5. **空气轴**：水汽、薄雾、微尘、灰烬、雪粉、雨线、花瓣或沙尘，最多一主一次。
6. **轮廓轴**：长垂直线、横向冠饰、宽袖弧线、窄袖行动线、硬甲块面或柔纱拖尾。
7. **脸部轴**：骨相、年龄、皮肤状态、眉眼方向、唇色边界和一种稳定标记。
8. **互动轴**：对视、交物、拒接、试探触碰、护持、追逐、围困、共同出手或群像仪式。

完成八轴后检查：人物、布景和动作是否来自同一个世界；若只是把八个漂亮元素并排堆放，重新删到一个主视觉事件。

## 色彩影调与灯光想象力

### 月蓝森林与局部暖肤

- 以靛蓝、月白和青黑建立夜林纵深，用树冠开口或洞口冷光形成可推断主方向。
- 人物正面保留很弱的中性或暖色反射，使眼睛、鼻梁和唇线可读，不把整张脸染蓝。
- 可用远处火点、灯笼或一件朱红衣料作为小面积暖色锚点。
- 月光保持稳定，变化来自树枝、云层和人物遮挡；薄雾只在光束中出现。

### 琥珀火室与橄榄黑暗部

- 让人物面部和手比背景亮1至2档，背景保留深木、橄榄黑、暗金和不同距离的火点。
- 主光来自侧前方火盆、灯烛或暖色墙面反射，近光眼出现眼神光，远光侧用负补光压出骨相。
- 火光低幅度不规则呼吸，高光依次经过眼睑、颧骨、手指、杯沿和金属，不让所有火点同频。
- 适用于私密谈判、饮酒试探、疗伤、审问和危险亲近。

### 朱红人物与青绿环境

- 朱红、胭脂或暗酒红由服装、帷帐、火场或花木承担，青绿、雾蓝或灰白由山林和天空承担。
- 红色角色靠色块分离，不依赖完整轮廓光；红衣内部必须有亮红、暗红和黑红折痕。
- 面部使用中性暖光，避免红光污染眼白、牙齿和全部肤色。
- 适用于决绝、牺牲、复仇、身份亮相和逆境反击。

### 珠白柔光与粉金高光

- 用乳白天空、浅纱、花枝、雪地或被照亮的水汽形成高亮背景，人物处于柔和中间调。
- 眼睛、眉毛、唇峰和发际线比皮肤更清楚；柔焦只软化高光边缘。
- 桃粉、淡金或浅翡翠只作妆造和背景小色块，不做现代糖水滤镜。
- 适用于初见、回忆、心动、伪装、静谧双人戏和脆弱时刻。

### 黄土逆光与暗红战争色

- 以赭黄、烟土、旧铁和低饱和暗红建立荒野或战场，天空和尘幕形成大面积逆光。
- 人物正面由地面与尘土反射补光，盔甲、剑锋和汗水只在角度成立时出现短促高光。
- 骑兵、旗帜、尘沙和衣摆遵循同一主风向；前景运动速度高于远景。
- 适用于军阵、追杀、突围、败退和命运尺度的远景。

### 特效光与真实底光并存

- 蓝色真气、火焰、符光或水纹必须有起势、增强、峰值、衰减和余辉。
- 特效只改变邻近皮肤、袖口、地面和雾气，远处区域按距离快速失去色彩溢出。
- 特效出现前先建立真实月光、火光或天光；特效熄灭后人物仍应处于可解释曝光中。
- 优先使用半透明气流、折射、热扰动、局部水波和光影位移，不默认实心光球。

## 布景与空间想象力

### 布景生成公式

每个场景选择：

**一个主结构 + 一组重复实景亮源 + 一个可运动介质 + 一条人物行动路径 + 一个纵深出口。**

例如不是只写“梦幻宫殿”，而是写“沿水池延伸的高低石台 + 远近错落烛阵 + 垂落纱幕 + 可绕行的窄桥 + 后方被月光照亮的门洞”。

### 可调用空间骨架

- **水榭长廊**：浅池、窄桥、反射地面、垂帘和远处门洞；适合对峙、跟随、倒影揭晓和水光动作。
- **竹影酒肆**：长柜台、酒器前景、竹帘侧光、客人剪影和后门出口；适合交物、试探饮酒、近距离谈判。
- **烛阵纱殿**：高低烛台、半透明纱幕、台阶和中心空地；适合仪式、审判、婚仪、权力登场和围困。
- **花树静庭**：低枝前景、花瓣地面、纱幔、浅水或石榻；适合心动、疗伤、隐瞒和临别。
- **洞窟天井**：岩壁、顶端裂口、潮湿地面、火盆和深处暗道；适合异人、内力修炼、怪物压迫和逃生。
- **林间光井**：树根、斜坡、倒木和树冠光口；适合埋伏、追逐、负伤停顿和一动一静的双人戏。
- **荒野军阵**：旗列、坡脊、骑兵通道、尘幕和远山；适合群像冲锋、包围、败退与个人命运对照。
- **囚笼式内室**：窗棂、珠帘、镜面、帷帐和重复竖线形成视觉牢笼；适合监视、伪装、身份压迫和想逃却未逃。

布景不得只作装饰。至少让一个结构参与剧情：帘幕遮挡视线、柜台限制距离、窄桥决定交锋路线、镜面暴露观察者、水池承接倒影、台阶建立权力差。

## 妆造、服装与人物轮廓

### 先从远景轮廓区分人物

- 掌权者可用横向冠饰、挺括肩线、厚重垂袖和较少无目的摆动。
- 游侠可用纵向长袍、不对称披挂、束腰和方便转身的窄内袖。
- 灵动人物可用短披肩、双髻或局部彩带，保持脚踝和手腕动作清楚。
- 异人可用白发、宽檐、半面遮挡或雕塑冠中的一种作为主识别点。
- 战将可用肩甲、护臂、披风和重型腰带建立块面，但保留髋部与手臂活动空间。
- 囚禁、婚仪或权力场人物可用层叠薄纱和珠链形成受限动态边缘，不能悬浮无重力。

### 材质组合不要单一

- 水洗丝 + 软皮 + 暗纹提花：游侠、谋士、浪客。
- 哑光缎 + 丝绒 + 金属窄边：掌权者、杀手、秘密组织。
- 象牙薄纱 + 银灰锦缎 + 淡金珠玉：清灵、异人、伪装身份。
- 朱红纱层 + 暗酒红缎面 + 古金节点：决绝、魅惑、婚仪与权力。
- 旧铁甲片 + 毛料 + 厚皮革：战将、边地强者和长期征战者。

让缎面高光移动、锦缎保持挺度、薄纱晚于身体响应、金属和珠饰产生短促滞后。造型夸张点越大，其他层越需要简化。

### 妆容跟随戏剧功能

- 清灵不等于苍白：保留暖象牙肤色、深瞳、自然唇纹和少量冷色眼尾。
- 华贵不等于满脸浓妆：强化眉形、唇色和一个珠玉或金属焦点。
- 邪异不等于黑眼圈：选择发缝色、额心印、眼尾弧线、深唇或局部白粉中的一种。
- 风霜不等于抹脏：用晒痕、胡茬、眼袋、嘴唇干裂和局部伤痕中的两三项建立经历。
- 心动或脆弱状态依靠泪膜、呼吸和暖光，不用高饱和腮红代替表演。

## 脸部样貌与银幕可读性

设计主要人物时，固定六至八项面部锚点，同时为每人选择一个“非标准美”特征，例如较宽鼻翼、厚下唇、外扩颧骨、短下巴、眼距偏宽、眉骨突出、真实眼袋、法令纹或轻微脸部不对称。

### 面貌差异轴

- **年龄**：少年皮肤紧实但可有疲态；成熟人物保留眼袋、法令纹和稳定下颌；老者保留皮肤松弛与眼神锐度。
- **力量**：宽额、高眉弓、厚下颌和颈肩连接表现力量；不必统一靠肌肉或胡茬。
- **机敏**：眉峰靠前、眼球转动快、嘴角反应灵活；脸型可短圆，也可窄长。
- **掌控**：眨眼少、眉弓清楚、下颌稳定、唇线边界明确；不依赖夸张瞪眼。
- **悲悯**：下眼睑稍厚、眉形平缓、嘴角自然下落、颧面柔和。
- **异相**：先保留真实骨相，再加入白发、面具、疤痕、异色瞳或额心标记中的一种。

同场多人至少在脸长、颧骨、下颌、眉眼、鼻形、肤色和年龄中拉开三项差异。灯光可以强化骨相，但不能替代骨相。

## 眼神戏与微表演

### 五段式眼神事件

把“看着对方”拆成：

1. **发现**：瞳孔先移动，头部暂时不动。
2. **确认**：视线停在眼睛、手、伤口、武器或出口中的一个具体目标。
3. **泄露**：眨眼、眉峰、鼻翼、唇角、下颌或呼吸发生一次细小变化。
4. **掩饰**：移开视线、低头、喝酒、整理衣袖或转向第三人。
5. **回看**：重新看回目标，态度与第一次不同。

单个镜头通常只使用其中两至三段；连续分镜可把五段分散到多个镜头。

### 可调用眼神关系

- **物件三角**：看对方的手中物，再看对方眼睛，最后决定接或不接。
- **越肩窥视**：前景人物看威胁，后景人物先看前景人的反应，再越肩确认威胁。
- **镜面暴露**：人物正面维持平静，镜中眼神先转向身后观察者。
- **笑意延迟**：眼睛先亮，嘴角晚半拍；适合狡黠、心动和假意顺从。
- **凝视中断**：眼神相接后，一方因伤口、武器、第三人或一句话移开，再强迫自己回看。
- **含泪不落**：眨眼变慢，泪膜只在受光角度变亮，下颌维持稳定，呼吸先失控。
- **异相压迫**：利用帽檐、面具或湿发遮住部分脸，只让一只眼获得眼神光；遮挡移动后才露出完整态度。

眼神戏必须与灯位协同：主要视线改变时，允许角色通过转头或横移进入另一片亮区，但不让灯光无原因追着眼睛移动。

## 单人动作与武打动作

### 四阶段动作句法

所有动作优先写成：

**意图出现 → 身体预备 → 主动作传力 → 余势与恢复。**

例如拔剑不是“迅速拔剑”，而是“眼神先锁定来路，拇指推开护手，肩胛下沉，后脚压实；手臂沿腰侧抽出剑身，剑尖最后找到目标；衣袖和发尾晚半拍甩出，呼吸与剑锋同时停住”。

### 文戏动作

- **饮酒试探**：先看杯中倒影或对方手，再举杯遮住部分表情；吞咽后不立即放下杯子。
- **递交信物**：手掌托物停在双方距离中点，接物者先看物再看人；是否接下成为剧情动作。
- **触碰面具或伤痕**：指尖接近前先停顿，触碰后观察对方眼睛；被触者先僵硬，再决定后退或允许。
- **拨帘入场**：手先分开帘幕，肩部进入，眼睛寻找目标，身体最后全部出现；帘珠在身后衰减摆动。
- **回头离去**：眼睛先转，头部跟随，脚步仍向前；若犹豫，只让步幅或手指变化，不让全身反复转身。

### 武打动作

- 一个镜头只设一个主动作信号：剑线、掌路、跃迁、格挡、冲撞或倒地。
- 攻击者先预备并明确力线，承受者沿接触点产生反应链，环境最后响应。
- 快动作使用方向性模糊和衣料拖尾，眼睛或接触点至少保留一个清晰锚点。
- 落地先由脚掌、膝或手接触，再传到髋、肩和头部；衣摆、尘土和饰品随后回落。
- 内力动作优先通过空气压缩、水纹、烛火偏斜、尘沙扩散和局部特效光表现，不让人物无原因悬浮。

## 双人动作互动

### 交物与拒接

- 主导者把物件送到双方距离中点，不直接贴到对方手里。
- 承受者先改变视线，再决定伸手、停手或把手收回袖中。
- 接触发生时，明确指尖、掌心或腕部位置；物件重量从一方转移到另一方。

### 试探触碰与撤回

- 触碰者先观察是否被允许，手指接近面颊、发丝或伤口时减速。
- 被触者可僵住、转眼、后退半步、抓住手腕或主动靠近，不能只保持写真表情。
- 撤回动作比接近动作更快或更迟疑，用速度差表达关系变化。

### 一人静止、一人绕行

- 掌权者或受审者保持中心位置，另一人横移、绕过前景或改变高度。
- 静止者只用眼睛跟随，直到关系转折才转头或起身。
- 摄影机可用轻微横移揭示距离变化，不默认环绕炫技。

### 追逐、保护与共同出手

- 追逐先建立领先者与追赶者的路径差，前景遮挡和地面条件影响速度。
- 保护动作明确挡身路线、抓握点和被保护者的被迫位移。
- 双人合击先区分各自攻击角度与节奏，再在同一目标上汇合；不要让两人做镜像动作。
- 动作结束后，双方根据体力、伤势和关系产生不同恢复状态。

## 多人调度与群像

### 三层权力构图

- 前景放置权力执行者、遮挡物或武器边缘。
- 中景放置当前情绪中心，获得最清楚的眼神光。
- 后景放置观察者、证人或潜在威胁，亮度低0.5至1.5档。
- 三层人物的视线必须落在同一事件链上，不能各自面对不同方向摆姿势。

### 中心静止与外围运动

- 仪式、审判或围困中，让中心人物保持克制静止，侍从、帷帐、火光或敌人沿外围移动。
- 外围动作按前后景错开，不同时同幅度挥袖、转头或拔剑。
- 权力反转时，中心人物第一次移动应成为唯一主动作信号。

### 队列与反向运动

- 行列、迎亲、送葬和军阵使用重复轮廓建立秩序，再让一人逆向、停步或回头打破秩序。
- 战场群像用前景横向快速运动、中景斜向冲突和远景纵深推进形成三种速度。
- 群像中的旗帜、尘沙、衣摆和骑兵方向必须服从同一风场和地形。

### 群像中的私密关系

- 两个核心人物可被人群、竹帘、酒器、花枝或烛台部分遮挡，形成“公共空间中的私人动作”。
- 用手部交物、短促眼神或肩后站位建立秘密关系，不必把所有人清空。
- 观察者必须看向具体接触点或其中一人的脸，并通过焦点或曝光确认其是否已发现秘密。

## 微场景与镜头组接

### 情感场景六拍

1. 建立人物距离和无法跨越的结构。
2. 用手中物、伤口、镜面或杯中倒影提出关系问题。
3. 切眼神确认，对方未必立即回应。
4. 发生一次真实接触或接触失败。
5. 一方掩饰、退开、转身或把话咽回去。
6. 后拉到空间，让布景重新强调命运关系。

### 动作场景六拍

1. 环境先出现异常：鸟惊、火偏、水纹、尘沙或人群停顿。
2. 主角眼睛找到威胁，身体进入预备。
3. 用一个近景交代手、脚、兵器或接触点。
4. 主动作爆发，摄影机保持方向清楚。
5. 承受者和环境依次响应，不同时爆炸。
6. 动作停止后保留呼吸、衣料回落、余辉和空间后果。

### 人物揭晓五拍

1. 先出现轮廓、背影、面具、帽檐或发丝。
2. 用道具或遮挡只露出部分脸。
3. 先切眼睛或嘴角的态度变化。
4. 通过摘面具、转身、抬眼或走入亮区完成揭晓。
5. 切旁观者反应，再回到完整关系镜头。

镜头组接优先使用眼神方向、手中物、火焰、水纹、衣料颜色或动作方向作视觉桥梁。不要连续堆放多张只有人物正脸的近景。

## 原创组合方法

每次从以下栏目各选一项，并至少制造一组对立：

- 影调：月蓝、琥珀、珠白、朱红、尘日。
- 空间：水榭、酒肆、纱殿、花庭、洞窟、森林、战场、囚室。
- 角色轮廓：横冠、长袍、红纱、白发、软甲、黑纱、短披肩。
- 表演事件：交物、拒接、回看、触碰、遮掩、保护、围困、共同出手。
- 动态介质：水纹、火焰、纱幕、花瓣、雨线、雪粉、灰烬、尘沙。

可用的原创对立包括：

- 柔和珠白花庭中的危险审问。
- 温暖烛室中的冷漠告别。
- 开阔尘日战场中的私密交物。
- 华丽纱殿中的狼狈负伤。
- 月蓝水榭中的朱红掌权者。
- 人群喧闹酒肆中的无声眼神结盟。

组合后用角色身份和剧情目的重新解释每个元素。若删掉某个元素不影响剧情、身份、动作或空间关系，就删掉它。

## 防止失控

- 不复制参考视频中的具体演员、角色、单件服装、标志性特效或完整镜头排列。
- 不把所有场景统一做成冷蓝夜景、烛海、白衣柔焦或桃花仙境。
- 不让灯光、布景、妆造、动作和粒子分别追求最大强度。
- 不用持续慢动作、持续凝视、持续飘纱或持续逆光代替剧情变化。
- 不让两人和多人使用相同表情、相同动作幅度或相同运动节奏。
- 不让群像平均亮、平均清晰、平均排布；必须有当前戏剧中心。
- 不用特效光替代真实底光，不用柔焦和烟雾掩盖脸部、手部与接触点。
- 不把真人骨相收窄为同一种尖下巴、大眼、高鼻梁和白瓷肤色。
- 不把想象力理解为无物理约束；材质、光线、承重、惯性、遮挡和环境后果仍需成立。
