# Realistic HK Wuxia

`realistic-hk-wuxia` 是一个面向 Codex 的香港新武侠提示词 Skill。它把人物、剧情、参考图、参考视频或分镜需求，转换为具有 1990 年代至 21 世纪初香港新武侠实拍质感的图像、分镜与视频提示词。

## 项目解决什么问题

它解决的核心问题不是单纯增加“8K、电影感、超写实”等风格词，而是让灯光、演员表演、服装材质、场景物理和武打动作属于同一个可信世界，减少塑料脸、静态死光、海报式站位、布料失重、武器穿模和游戏特效感。

> 本项目生成提示词，不直接调用生图或视频平台，也不包含模型、API 密钥或生成额度。

## 主要功能

### 灯光与色彩优先

- 所有提示词先输出“灯光与色彩影调”定调，再描述人物和剧情。
- 明确曝光层级、主导色、对置色、点睛色、肤色基准、主光、环境光、负补光和局部轮廓光。
- 为烛火、火光、灯笼、月光、星光、水面反射和内力特效光设计随时间变化的光线行为。
- 让阴影、眼神光、皮肤、金属、缎面、水面和布景反射同步响应光线变化。
- 微尘、细沙、灰烬、水汽或雪粉只在受光体积中显形，并服从风向、气流与景深。

### 三种视觉模式

- **克制真人实拍**：默认模式，强调真实演员、自然胶片、现场光源和物理可信度。
- **港片暖润高光**：使用蜂蜜金、琥珀光、亮人物与深暖背景，保留清楚的眼睛和面部结构。
- **浓郁复古梦幻**：允许更明显的冷暖对比、Soft Orton、高光卤化、烟雾和丁达尔光，但仍保持真人与实景逻辑。

### 真人演员与剧情表演

- 将“悲伤、心动、震惊、杀意”等抽象情绪转换为视线、眨眼、呼吸、停顿、嘴唇、手指和重心变化。
- 支持双人贴近、搀扶、托抱、挟持、共同出手和多人群像调度。
- 通过脸型、颧骨、下颌、眉形、眼型、鼻形、唇形和稳定标记建立人物识别锚点。
- 保留适量皮肤纹理和自然不对称，避免蜡像磨皮、网红同脸和过度 HDR。

### 香港新武侠妆造

- 根据人物阶层、财富、门派、职业、性格和行动需求设计服装。
- 支持丝绸、锦缎、提花、缎面、薄纱、欧根纱、皮革、毛料、金属、珠玉和混合织物。
- 允许 1990 年代至 21 世纪初香港新武侠常见的大胆配色、高冠、发辫、雕塑感盘发、不对称剪裁和戏剧化妆容。
- 用真实重量、固定方式、惯性、受潮和磨损约束造型，避免廉价 cosplay 或游戏盔甲感。

### 单图、分镜与视频

- **单幅图像**：输出完整灯光定调、剧情核心、人物表演、布景、妆造、摄影机参数和负面提示词。
- **连续分镜**：先建立全组共用的灯光与色彩圣经，再逐镜描述时长、景别、机位、动作、表演、声音和连续性。
- **视频提示词**：按时间段组织起始状态、动作、运镜、对焦、光线变化、环境响应和结束状态。
- 可按即梦、可灵、海螺、Runway、Pika、MiniMax 等平台的提示词倾向压缩或细化表达，但不会直接连接这些平台。

### 高速真人武打导演

- 支持剑法、刀法、掌法、轻功、双人合击、群战、内力与剑气。
- 强制动作具备最小前摇、脚步与腰胯传力、明确接触、身体受力、惯性余势和变招续接。
- 维持兵器数量、左右手、人物位置、攻击轴线、伤势与前后镜头连续性。
- 支持险距镜头、方向性运动模糊、兵器 POV、动作追拍、声音设计和清晰视觉锚点。
- 内力遵循“暗起—聚集—峰值—爆开—衰减”，剑气贴合兵器轨迹，避免霓虹激光和站桩对波。

### 参考图与参考视频

- 人物参考图用于锁定面貌、发型、服装、武器和配饰。
- 风格参考图只提取色彩、颗粒、布光和镜头质感，不替换人物身份。
- 参考视频用于提炼曝光组织、颜色信号、空间骨架、动作节拍和镜头连接方式。
- 只复用视觉关系与方法，不复刻具体演员、服装、特效或完整镜头顺序。

## 安装方法

### 方法一：安装 Release 压缩包

1. 下载最新的 `realistic-hk-wuxia-*.zip`。
2. 解压后确认最外层目录名为 `realistic-hk-wuxia`，其中直接包含 `SKILL.md`、`agents/` 和 `references/`。
3. 将整个目录复制到 Codex 的技能目录。

Windows 默认安装位置：

```text
C:\Users\<你的用户名>\.codex\skills\realistic-hk-wuxia
```

macOS / Linux 默认安装位置：

```text
~/.codex/skills/realistic-hk-wuxia
```

Windows PowerShell 示例：

```powershell
Expand-Archive -LiteralPath .\realistic-hk-wuxia-latest.zip -DestinationPath .\skill-package
Copy-Item -LiteralPath .\skill-package\realistic-hk-wuxia -Destination "$env:USERPROFILE\.codex\skills" -Recurse
```

### 方法二：从源码安装

克隆仓库后，将仓库中的 `realistic-hk-wuxia` 技能目录完整复制到 Codex 技能目录，不要只复制 `SKILL.md`。

安装完成后重新打开 Codex，或新建一个任务，让技能列表重新载入。

## 使用方法

在 Codex 对话中显式调用技能：

```text
$realistic-hk-wuxia 你的需求
```

一个有效输入通常包含以下信息中的若干项：

- 人物和关系
- 剧情动作与结果
- 场景、时间、天气
- 单图、宫格分镜或视频时长
- 画幅比例
- 期望的视觉模式
- 参考图分别负责人物、服装还是影调
- 武打中的兵器、人数、招式和胜负走向
- 目标生成平台

简短需求也可以使用，缺失信息会依据剧情合理补齐。例如：

```text
$realistic-hk-wuxia 楚留香与水母阴姬在水宫对峙，4宫格分镜，16:9，港片暖润高光。
```

涉及参考图时，上传图片并明确职责：

```text
$realistic-hk-wuxia 图1锁定杨过，图2锁定小龙女，图3只参考火场影调。生成20秒双人合击金轮法王的视频提示词，最后二人负伤，适配可灵。
```

## 输入输出示例

### 示例一：四宫格剧情分镜

**输入**

```text
$realistic-hk-wuxia 雪夜风陵渡口，郭襄看到杨过摘下面具后看呆了，背后是神雕。4宫格分镜，16:9，克制真人实拍。
```

**输出节选**

```text
灯光与色彩圣经：低调雪夜曝光，冷蓝灰月夜为主导色，渡口灯笼的低饱和琥珀色为对置色。月光从左后上方穿过薄云缓慢变化，灯笼受侧风小幅摆动，郭襄的肤色保持中性偏暖；雪粉只在灯笼和月光交叠的受光区域短暂显形。35毫米胶片颗粒，克制卤化，黑位保留木构与湿石层次。

镜头1｜建立关系：35mm中远景，郭襄站在前景右侧，杨过与神雕位于中后景；风从左向右推动雪、发带和衣摆。
镜头2｜揭晓：65mm中近景，杨过抬手摘下面具，眼睛先看向郭襄，面具离开面部后手腕自然下沉；灯笼暖光沿他的颧骨短暂移动。
镜头3｜反应：85mm郭襄特写，她先停止眨眼，呼吸停半拍，视线从面具移到杨过双眼，嘴唇微张后又克制合拢。
镜头4｜收束：50mm双人关系镜头，杨过略偏身，神雕在背后抖落肩羽积雪；郭襄仍停在原地，灯笼摆回时暖光从她眼中掠过。

负面约束：海报式站位，人物直视镜头，静态死光，满屏均匀飞雪，完整轮廓光，塑料皮肤，服装失重，四格人物身份漂移。
```

实际输出还会包含每格时长、镜头功能、焦段、运镜、声音和前后连续性。

### 示例二：高速武打视频

**输入**

```text
$realistic-hk-wuxia 小龙女与杨过双人合击金轮法王，20秒真人武打视频。残破佛殿火场，最后二人被金轮法王震伤，少量台词，21:9，适配可灵。
```

**输出节选**

```text
灯光与色彩影调：低调火场，深炭黑与冷蓝夜色为基底，左后方坍塌木架的火焰提供琥珀主光。火势非周期起伏，暖光随火舌爬过脸颊、剑身和金轮后迅速回落；金轮内力峰值只在接触瞬间形成短促互动光，灰烬只在火光束内显形。

0-4秒：35mm贴地前冲建立三角站位。杨过从左侧压低重心抢中线，小龙女从右后方半拍切入，金轮法王持续转腰换步，不站桩等待。
4-9秒：双剑一高一低交错逼近，脚掌蹬地、髋部旋转、肩肘传力后剑锋才加速；镜头横向追拍，眼睛和第一次兵器接触点保持清晰，剑尖与衣袖出现方向性运动模糊。
9-14秒：金轮沿外缘回旋格挡，轮剑相撞后火星与半透明压力波快速扩散并衰减；杨过前臂被震开，小龙女顺势换位补上空门。
14-20秒：金轮法王沉肩踏裂地砖，以腰胯推动重轮反震。接触前从轮缘POV切回客观侧面，清楚交代两人胸腹受力、失去支撑和落地吸收。杨过落地后短促喊：“姑姑！”小龙女撑剑抬眼，没有立刻起身。

负面约束：大幅慢速蓄力，轮流进攻，站桩对波，兵器穿模，受击无反馈，全局运动模糊，霓虹激光，巨大魔法阵，持续全身发光。
```

## 能力边界

- 不直接生成图片或视频，只输出可用于生成平台的提示词与镜头设计。
- 不适用于二次元、三渲二、游戏 CG、纯商业海报或无剧情目的的写真。
- 参考图和参考视频用于维持角色与提炼视觉语法，不保证第三方生成平台能够完全保持人物一致性。
- 最终效果仍受所用模型、平台版本、参考图质量、时长和参数限制影响。
