## 使用范围与优先级

用户要求武侠打斗视频、动作分镜、剑法刀法掌法、轻功、合击、群战、内力或剑气时读取本模块。也用于修复出手太慢、人物站桩、轮流进攻、运镜平淡、打击无反馈、武器穿模或特效像游戏的问题。

本模块只负责动作、空间、镜头、剪辑与声音。主技能的规则仍然优先：

1. 最终提示词必须以灯光与色彩影调开头。
2. 人物面貌、服装、兵器数量、左右手、伤势和空间方向必须连续。
3. 动态灯光服从可见光源和时间行为；内力光只能在峰值短暂参与照明。
4. 真人表演、重量、重力、接触点和受力反馈优先于炫技特效。
5. 风、雨、雪、烟、衣料、发丝和环境碎屑必须处于同一物理世界。

可输出给即梦、可灵、海螺、Runway、Pika、MiniMax 等视频模型。用户指定平台时按平台习惯压缩措辞；未指定时输出平台中性的可执行中文提示词。

## 输入与总控

除主技能的常规输入外，武打视频优先锁定：

- 视频时长、画幅和是否需要分秒时间线
- 对战人数、人物关系、当前伤势和胜负走向
- 每件兵器的数量、结构、持有者、左右手与初始位置
- 功法的起手、传力、轨迹、接触点和环境反馈
- 战场平面、前中后景、可借力结构、出入口和攻击轴线
- 主要杀招、速度变化、是否使用慢动作及使用时长
- 摄影机起点、运动方向、焦点锚点和剪辑方式
- 台词、呼吸、兵器声、环境声和口型同步要求

缺失信息可以按人物与场景合理补齐，但不得改变用户明确设定。默认只设计一个主要动作峰值，其余动作负责建立、逼近、变线和收束。

在动作段开头加入以下总控语义，并按剧情改写：

> 这是一场由专业武术指导设计的真人武侠近身交锋，不是站桩放技能或轮流表演。所有人物始终处于战场状态，持续进攻、防守、试探、换位、抢位或准备切入。动作具有清晰传力链、兵器接触点、身体受力、环境反馈、空间轴线和快慢节奏变化。

## 动作传力与速度

每个主要招式按以下链条设计：

> 眼神锁定 → 最小预备 → 脚步启动 → 腰胯传力 → 肩肘腕递进 → 兵器或掌力接触 → 身体受力 → 惯性余势 → 变招续接

必须做到：

- 眼睛先发现目标，头部与身体晚半拍跟随。
- 脚掌先建立支点，力量再经过膝、髋、脊柱和肩臂传至兵器。
- 写清攻击路径、接触部位、受力方向和结束姿态。
- 受击者出现偏移、失衡、补步、震手、收肩、塌膝或呼吸中断。
- 发丝、衣袖、袍摆、尘土、水花或雪粉晚半拍响应冲击。
- 一招结束立即进入抢位、防守或下一次变招，不原地收势摆拍。

高阶快剑和短兵器遵循“最小前摇、最短路径、中线切入、接触急停、利落收招”。速度来自突然启动、险距、路径效率和节奏对比，不来自整幅画面持续模糊。

可选动作词：瞬拔、袖下藏锋骤出、半步入怀疾刺、斜线抢中门、贴肋切入、肘下窜锋、虚一实二、低位滑切后骤然上挑、擦身反抹、回腕断线。每次只选符合兵器和空间的两至四项。

慢动作只用于关键接触前后极短片段，用来显示目光、锋刃距离、接触压缩或身体吸收；前后必须恢复真实高速。

## 持续战场与空间调度

未主攻角色也要持续追踪视线、调整重心、改变兵器角度、观察第二路径、封路、抢位或准备救援。禁止“一人打完，另一人再上”。

多人战斗使用错拍进攻、多角度夹击、高低位分工和同时威胁。保持当前戏剧中心清楚，背景角色承担压迫、封路或投射攻击，不让所有人做相同动作。

根据场景选择三至六个空间动作：

- 跳斩、翻身回刺、半空变向、凌空压顶
- 踏墙反蹬、借柱翻轴、借竹回弹、借屋檐俯冲
- 贴地滑切、掠水滑步、滚身闪避、倒挂下滑
- 回身换位、贴身绕背、借兵器反震二次进攻

轻功必须写明起跳来源、借力结构、空中改线和落地吸收。人物落地时屈膝、移胯、鞋底摩擦或水面下陷，随后立即再起；禁止无重力悬浮。

场景必须参与战斗。用完整因果链书写：

> 接触场景结构 → 结构受力或变形 → 人物获得速度、遮挡或改变方向 → 对手即时应对

可使用竹竿弯曲回弹、石壁反蹬、屋檐落差、栏杆和门框遮挡、帘幕或绳索旋转、湿地滑行、水面反作用、对手兵器反震与对手惯性空门。不要只把布景当漂亮背景。

## 兵器险距与打击反馈

关键交锋进入一线生死的近身距离：剑锋擦脸、刀尖贴喉、轮刃掠鼻、枪头擦肩、掌风贴耳或剑尖沿手腕和腰线滑过。险距镜头短、快、清晰；兵器不得穿模，人物必须即时闪避、格挡或受力。

每次重要碰撞至少写出四类反馈：

1. 接触：金属震鸣、布帛撕裂、闷响或短促火星。
2. 身体：肩背偏移、胸腔收缩、手腕震麻、膝盖塌陷或脚步补偿。
3. 环境：水花、灰尘、雪粉、碎石、竹叶、旗幡或灯火响应。
4. 镜头：短促震颤、瞬间推近、急停或快速后拉。

重击节奏使用：

> 高速逼近 → 接触压缩 → 半拍停顿 → 冲击爆开 → 身体吸收 → 余势回落

冲击反馈强弱应匹配兵器重量、人物能力、落点和地面摩擦。禁止仅靠大幅拖影表现力量。

## 内力、剑气与奇异功法

内力必须经历：暗起 → 聚集 → 增强 → 峰值 → 爆开 → 衰减。

用空气折射、雨线偏折、水面凹陷、水汽推开、灰尘或雪粉震散、竹竿压弯、衣料受气压和地面碎屑表达力量。峰值光只短暂照亮邻近脸侧、兵器、衣料和地面，并与主场景灯光发生可解释的曝光变化；禁止持续全身发光和无来源光球。

剑气严格贴合剑锋轨迹，是半透明空气压力刃、冷白或银蓝水纹折射与极薄光学残痕，不是实心激光。它在碰撞点压缩、短停、爆开并迅速衰减，同时切开雨幕、水汽、尘土或雪粉。刀气、掌风和轮刃气压也必须服从各自运动轨迹。

每种奇异功法至少拥有四个差异：

1. 独特起手方式
2. 独特传力结构
3. 独特攻击轨迹
4. 独特环境反馈

不得用不同颜色的发光代替功法差异。先设计物理作用，再选择克制的光学表现。

## 残影、合击与群战

残影是高速位移留下的短暂时间差叠影，不是复制人。每道残影姿态和攻击阶段不同，越早越透明，本体始终可辨，存在时间极短，不整齐排队，也不改变人物面貌和服装。

双人合击采用不对称分工：一高一低、一引一刺、一封一破、一快一重、前后错位，并保留半拍时间差。两人的兵器轨迹互补但不互撞；峰值时力量在目标前方压缩、短停后同时爆开。禁止镜像舞蹈。

一敌二时，主敌保持或主动移动中轴，两名进攻者从不同高度、角度与时间切入；主敌持续回轮、换步、转腰和反击。群战切镜必须保留左右关系、进退方向与攻击轴线，禁止人物一字排开。

## 运镜、剪辑与清晰锚点

镜头追随动作，不等待动作。按动作目的选择贴地前冲、快速推近、急速后拉、横向追拍、跟兵器轨迹摇移、甩镜接变招、前景遮挡转场、接触点瞬间推近或冲击后快速抽离。

关键杀招可加入一次短促的第一视角或准第一视角兵器跟拍，例如贴剑脊突刺、跟随轮缘旋转或沿掌风推进轴前冲。接触前一瞬切回客观侧面，让观众清楚看见闪避、格挡、命中和受力；不得长时间用主观镜头替代空间交代。

剪辑节奏：

> 建立 → 加速 → 骤快 → 险距短切 → 重击压停 → 再爆发 → 峰值 → 余震收束

允许动作连续切、遮挡切、甩镜切、兵器掠镜切、POV切回客观、接触点强化切和爆发前抽静。禁止无意义乱切、频繁越轴和用镜头晃动掩盖动作不清。

高速段始终保留至少一个清晰锚点：眼睛、脚步落点或兵器接触点。允许剑尖末端、衣袖、发梢、雨滴、水花和轮缘出现方向性运动模糊；禁止人物脸、兵器和环境同时糊掉。

## 表演与声音

战斗表演必须参与动作逻辑：眼神先锁定目标，瞳孔跟踪兵器与空门，发力前压气或短吸气，重击后呼吸中断或急促吐气，下颌、肩颈、鼻翼和握力产生微变化，受击后身体主动寻找恢复重心的路径。禁止永久瞪眼、持续怒吼和模特式摆拍。

声音按动作因果安排：兵器破风、金属震鸣、布料摩擦、脚步、踏水、竹竿回弹、碎石、水花、内力低频压缩和人物呼吸。关键碰撞前可短暂抽掉环境声，只保留呼吸、心跳或剑身震鸣；爆发后让环境声重新涌入。

## 输出模板

单段直接提示词按以下顺序：

1. 灯光与色彩影调定调
2. 人物和参考图身份锁定
3. 真人武术总控与战场空间
4. 分秒动作、传力、接触和受力
5. 运镜、焦点、剪辑与光学特效
6. 表演、台词、呼吸与声音
7. 结束状态、连续性和负面提示词

时间线分镜按视频长度切分，不机械固定秒数。每段都写明：镜头目的、人物位置、动作链、接触点、空间轴线、摄影机、清晰锚点、灯光相位、环境响应、声音和段尾状态。下一段必须从上一段的真实位置、重心和兵器状态继续。

优化旧提示词时，先用一至三句指出核心问题，再给完整替换版。优先修正站桩、慢前摇、接触缺失、轴线混乱、全局模糊和特效光污染。

## 负面约束与质检

按任务选择负面词，不机械堆满：

> 慢速蓄力出剑，大幅前摇，站桩互殴，轮流出手，原地摆姿势，长时间静止对视，匀速舞剑，持续慢动作，固定机位展示，镜头乱晃，缺少空间位移，动作没有传力，攻击没有接触点，受击无反馈，人物瞬移，无起跳悬浮，兵器穿模，肢体粘连，多余肢体，残影排成一列，残影换脸，动漫动作，游戏CG，站桩对波，霓虹激光，实心光球，巨大魔法阵，持续全身发光，塑料皮肤，海报式站位，空间轴线混乱，文字，字幕，水印

输出前检查：

- 是否有最小前摇、完整传力、明确接触、身体受力和余势续接？
- 未主攻角色是否仍在观察、换位、封路或准备切入？
- 是否使用场景完成借力、遮挡或变线，并写清因果？
- 武器数量、持有者、左右手、人物位置与攻击轴线是否连续？
- 是否有险距镜头、动作追拍和至少一个持续清晰的视觉锚点？
- 使用兵器POV时，是否在接触前切回客观视角交代结果？
- 内力是否有起、涨、峰、退，剑气是否紧贴兵器轨迹并快速衰减？
- 残影是否为时间差叠影，合击是否具有分工和半拍差？
- 灯光、特效互动光、环境介质与人物受力是否同步而不遮住五官和接触点？
- 动作、镜头、声音和结束状态是否构成同一条因果链？

三项以上不通过时，先重写动作段再输出。
